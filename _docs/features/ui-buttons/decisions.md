# UI buttons: decisions

## D1. Plain plank, arrow plank for the pick (2026-10-26, user)

- **Decision:** a menu item is the plain wooden plank; the picked one is the right-pointing
  arrow plank, drawn into the same box (hit areas don't change). Disabled items are darkened.
  Text is dark brown on the gold face.
- **Rejected:** the hexagon plank with a glow; the plain plank with a tint only.

## D2. Whole-game scope (2026-10-26)

- **Decision:** besides the planks: the wooden board behind every menu, an icon left of each
  item, the volume drawn as the 5-segment bar (0–10 as half segments) with the speaker /
  mute icon, and the wooden arrows (turned) for the travel menu's scroll marks.
- **Why:** the user asked for the sheet "in the whole game" and said "go with the
  recommendation" without picking a scope; these are the parts with a clear use. The user
  can veto any of them.

## D3. Slicing instead of plain scaling (2026-10-26)

- **Decision:** planks are drawn in 3 slices and the board in 9: the ends keep their shape at
  any width and only the middle stretches. The slice insets are measured from the sheet.
- **Why:** labels differ in width; a scaled plank squashes its ends.
