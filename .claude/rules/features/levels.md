# Feature: levels

Docs for this feature live in `_docs/features/levels/`.

- Before changing code here, read `_docs/features/levels/state.md` (where work stopped)
  and `tasks.md` (what's next), then follow its `README.md` only as far as the task needs.
- After any piece of work here, save the state: `/feature-docs update`. Link facts; don't copy them.
- A level uses only its own tiles, background and enemies (`_docs/features/levels/spec.md`).
- Asset files need unique base names: never two `day.png`.
